Imagens dos posts

Este projeto usa o campo image no front matter de cada ficheiro em _posts.

Exemplo no post:
image: /assets/images/posts/2024-05-12-cronica-abril-2024.webp

Como substituir imagens:
1. Coloque o ficheiro nesta pasta.
2. Edite o post correspondente em _posts/ e atualize o campo image.
3. Recomendado: formato 1200x630 em JPG, PNG ou WEBP.

Fallback:
- Quando nao existe imagem definida, usa-se /assets/images/posts/post-placeholder.svg.
